使用 Jenkins 持续集成 iOS 项目时碰到的一些问题

文章发布较早，内容可能过时，阅读注意甄别。

使用Jenkins打包时，本地电脑是可以正常使用pod install 命令的，但是通过Jenkins shell脚本就报错，导致pod无法安装

iOS 项目使用了 Cocoapods 时，执行 pod install 脚本报错：pod: command not found

+ pod install

/var/folders/9d/jrxjl4_14tj1w33z34jkrxjm0000gn/T/hudson943803671821413828.sh: line 5: pod: command not foundBuild step 'Execute shell' marked build as failure
1
2
3

解决方案如下： 在Jenkins的 Build Script中顶部添加下面代码即可

#!/bin/bash -l

export LANG=en_US.UTF-8

export LANGUAGE=en_US.UTF-8

export LC_ALL=en_US.UTF-8

pod install --verbose --no-repo-update
