    # Hexo博客主题pure使用说明

    A brand new default theme for [Hexo (opens new window)]. Preview (opens new window) | English documentation (opens new window)

    # (opens new window)外观

    首页 (opens new window) | 归档 (opens new window) | 分类 (opens new window) | 标签 (opens new window) | 项目 (opens new window) | 书单 (opens new window) | 友链 (opens new window) | 关于 (opens new window)

    # (opens new window)启用主题

    Execute the following command under your hexo folder.

    git clone https://github.com/cofess/hexo-theme-pure.git themes/pure

    Then modify the property theme of the file hexo/_config.yml to theme: pure

    # (opens new window)更新主题

    Execute the following command to update theme.

    cd themes/pure
git pull

    # (opens new window)搜索

    主题内置三种站内搜索方式：insight、swiftype、baidu

    # Search
search:
 insight: true # you need to install `hexo-generator-json-content` before using Insight Search
 swiftype: # enter swiftype install key here
 baidu: false # you need to disable other search engines to use Baidu search

    # (opens new window)友情链接

    复制theme/pure/_source/ 目录下links文件夹到blog path/source/ 目录下

    在 hexo 目录下的 source 文件夹内创建一个名为 _data（禁止改名）的文件夹。不操作的话友情链接里面为空白。。。

    然后在文件内创建一个名为 links.yml 的文件,在其中添加相关数据即可。

    单个友情链接的格式为：

    Name:
 link: http://example.com
 avatar: http://example.com/avatar.png
 desc: "这是一个描述"
    1
    2
    3
    4

    添加多个友情链接，我们只需要根据上面的格式重复填写即可。

    . 将 Name 改为友情链接的名字，例如 Nick5683。

    . http://example.com (opens new window) 为友情链接的地址。

    . http://example.com/avatar.png (opens new window) 为友情链接的头像。

    . 这是一个描述 为友情链接描述。

    # (opens new window)文章启用目录索引

    # (opens new window)hexo-translate-title (opens new window)

    使用Google翻译，百度翻译和有道翻译将Hexo中的汉字标题转成英文标题

    安装

    npm install hexo-translate-title --save
    1

    在博客配置文件_config.yml中添加

    translate_title:
 translate_way: google    #google | baidu | youdao
 youdao_api_key: XXX
 youdao_keyfrom: XXX
 is_need_proxy: true     #true | false
 proxy_url: http://localhost:8123

    # (opens new window)数学公式

    Hexo默认使用"hexo-renderer-marked"引擎渲染网页，该引擎会把一些特殊的markdown符号转换为相应的html标签

    # (opens new window)解决方案

    解决方案有很多，可以网上搜下，为了节省大家的时间，这里只提供亲身测试过的方法。

    更换Hexo的markdown渲染引擎，hexo-renderer-markdown-it-plus (opens new window)引擎替换默认的渲染引擎hexo-renderer-marked (opens new window)即可。

    # (opens new window)安装hexo-renderer-markdown-it-plus插件
    npm un hexo-renderer-marked --save
npm i hexo-renderer-markdown-it-plus --save
    1
    2
    # (opens new window)配置

    安装插件后，如果未正常渲染LaTeX数学公式，在博客配置文件_config.yml中添加

    markdown_it_plus:
 highlight: true
 html: true
 xhtmlOut: true
 breaks: true
 langPrefix:
 linkify: true
 typographer:
 quotes: “”‘’
 plugins:
 - plugin:
 name: markdown-it-katex
 enable: true
 - plugin:
 name: markdown-it-mark
 enable: false
